# 📊 CotiPlus - Cotizador para Centro de Impresión

Una aplicación interactiva diseñada para calcular de forma rápida y precisa los costos de impresión en base a diferentes parámetros (tamaño de papel, tipo de tinta, cantidad, etc.).

## 🚀 Características principales
* 💰 **Cálculo automático:** Presupuestos instantáneos según el volumen.
* 📄 **Soporte multiformato:** Opciones para diferentes tipos y tamaños de papel.
* 🖥️ **Multiplataforma:** Compatible con entornos web, de escritorio (Electron) y móviles (Capacitor).

## 🛠️ Tecnologías utilizadas
* **Vite + React / Vue / TypeScript** (Tu framework principal)
* **Capacitor** (Para la exportación móvil)
* **Electron** (Para la aplicación de escritorio)

## 📦 Instalación y uso local

Si deseas probar o colaborar en este proyecto localmente, sigue estos pasos:

1. Clona este repositorio:
   ```bash
   git clone https://github.com
   ```
2. Instala las dependencias necesarias usando `pnpm`:
   ```bash
   pnpm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   pnpm dev
   ```
